# Method/data coverage and next learning work

More acquired media is not more qualified methods. No single generic accuracy
percentage combines detection, method identification and exact payload recovery.
Preserve all failed historical gates. Raw restricted corpora and learned weights
remain private until their usage/publication conditions are independently cleared.

DIV2K train and validation are one origin; BOSS acquisitions are one origin.
BOWS camera/scene independence remains unknown. WIFD's whole origin stays
reserved from fitting/calibration. ESC-50 categories are environmental context,
not stego classes. Native folds cannot be blindly trusted: the retained failed
ESC run and explicit grouped retry prevent two source IDs leaking between
validation and test. Never move held-out recordings back into training to
restore a desired count or improve observed results.

Training and model choice must not repeatedly consult previously inspected
validation failures. Freeze each intervention/control and calibration policy;
report per-format/method/rate/source cells, false positives, uncertainty and
exact recovery separately. Only the original real-data/independent-source gates
can qualify support. Extra VRAM is capacity, not evidence of generalization.
