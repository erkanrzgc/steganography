# Native PNG/BMP pilot attribution — 2026-10-23

These six originals were obtained through Wikimedia Commons under the
file-specific licenses below. Original media and prepared derivatives
remain private; this document publishes attribution metadata only.

Prepared variants use a fixed top-left 256×256 crop and PNG/BMP encoding.
The generated `lsb-control` variants additionally replace plane-0 bits
with a 32-byte generated payload. Cover variants contain only the crop
and format changes. Attribution implies no creator endorsement.
