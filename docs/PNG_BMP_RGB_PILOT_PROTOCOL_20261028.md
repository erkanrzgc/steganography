## Live closing evidence and projection

The worker stays alive after all computation, numeric-state verification and
source revalidation. A separate observer hashes bounded regular output files
and reads that live process's cgroup-v2 `memory.max`, `memory.swap.max`,
`memory.current` and `memory.peak`. It writes an exclusive bound receipt before
releasing the worker. Kernel systemd monotonic start/exit timestamps independently
bound process time. Post-exit source/output replay checks every observed hash;
final charged time is at least both worker elapsed time and kernel execution.
The outer controller also enforces the full command deadline, including SSH,
evidence transport, unit stop and closing write. It retains the immutable
worker/kernel acceptance and writes a separate exclusive `closed.json` whose
debit includes measured parent elapsed time plus a five-second closing reserve.
Only that final closure may be bound by later fit approval. Eligibility is
rechecked against this larger cumulative debit; expired parent time is
unavailable. All heavy worker work precedes the live memory observation. A released post-exit
cgroup peak is not required; this does not repair old failed observers.
The private source-bound controller, deployment and observer code are included
in the protocol closure. Source-only staging is exclusive and independently
hash-verified before launch. Neither cache regeneration nor package installation
is part of staging. Numeric states remain private on WSL.

The projection conservatively sums, per seed, 320 times the largest measured

## Later approval-bound optimizer phase

A distinct approval JSON must bind the exact protocol SHA-256, accepted profile
SHA-256 and split SHA-256, user approval and cumulative time/output ceilings.
The runner refuses to construct the native fit output or update an optimizer
without this binding. It retains the profile's independent time/storage debit.

The fixed recipe is RGB SRNet, both original model seeds, payload seed
2026102805, paired FP32 batch eight and scalar AdamW: learning rate 0.0001,
betas (0.9, 0.999), epsilon 1e-8, zero weight decay, foreach/fused disabled.
Each seed receives twenty full epochs: sixteen updates/epoch, **320 updates /
2,560 presentations**. Both seeds total **640 /5,120**. Fresh initialization,
model-seeded epoch permutations and payloads are reproducible. No tuning,
validation-threshold sweep, adaptive seed choice or early learning stop.
All intent/commit steps and losses are retained, including partial failure.

Initial/final train and development score pairs are retained for independent
pairwise AUC replay. An exploratory seed passes only with final train AUC at
least .85, development AUC at least .70 and last-epoch mean loss at most .80
of first-epoch mean loss. Both seeds must pass; failure still records both
complete schedules if resource guards permit. This small author-grouped pilot
cannot qualify a production detector or replace independent reserved testing.
No deployment or reserved-data evaluation is authorized by a pilot pass.

Numeric checkpoints at epochs 5/10/15/20 yield eight states. They carry the
source/data/recipe/environment bindings, model/optimizer/RNG, epoch order and
consumption. Truncation, bad hashes, symlinks, overwrite, incompatible software
and changed data order are rejected. Their existence grants no retry or resume
of a consumed attempt; continuation software is tested on generated fixtures.
Every checkpoint is reserved against the measured size bound before writing.
