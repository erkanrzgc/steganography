## Verification and resource accounting

The unchanged full gate passes **3,321 tests /two actual-CUDA skips**, with
**96.81%** total coverage and **100%** for both new modules. Ruff and 210-file
mypy pass. Forty-eight focused scalar/security cases cover malformed inputs,
hash/license/domain checks, ZIP member/encryption bounds, symlinks/FIFOs,
overwrite, duplicate originals, mutation and size/time limits. The 63-case
documentation/preparation repair check also passes. Python 3.11 is checked
locally; the 3.12–3.14 matrix remains unverified here.

The first full attempt failed the unchanged README length gate: 3,320 passed,
one failed, two CUDA skips. It produced no real corpus. The README was shortened
while retaining all eight measured-result rows; no test or coverage requirement
was weakened. The fresh full gate then passed before the single real preparation.
The [failed receipt](../benchmarks/all-format-local-results-20261016.json),
[explicit repair binding](../benchmarks/all-format-local-readme-repair-20261016.json)
and [successful verification](../benchmarks/all-format-local-retry-verification-20261016.json)
remain separate. Initial focused harness failures are also preserved privately.

Preparation took **0.1045 seconds including imports**, peaked at **40,404 KiB
resident memory**, and retained **519,675 bytes including licenses/manifest**.
The owned process had one CPU, 512-MiB memory, zero swap, a 120-second CPU/
preparation allowance and 16-MiB output bound. Both owned services exited
successfully and are inactive; no automatic retry is pending.

Full verification took 1,009.45 seconds with **155,845,096 bytes** of observed
peak task outputs. The recorded native footprint at publication is
**684,623,343 bytes**, below four GiB, preserving the six-GiB JPEG reserve.
All prior 18/27-file native, 35-file JPEG and 30-file WAV source closures, the
four new preparation sources and all 14 old numeric models remain unchanged.
