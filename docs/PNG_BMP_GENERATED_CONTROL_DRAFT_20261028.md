# Generated spatial learning control — non-executable draft, 2026-10-28

This is a proposed new intervention for the generated-only APIs, not a retry
of any Colab/JPEG/WAV run and not permission to fit native images. No new GPU
profile or full learning experiment has run. Finalize and source-bind an
executable supervisor, independent debit ledger and complete acceptance
contract before requesting execution approval. Existing recipes and budgets
remain immutable; no native media, download or real split is used here.
The [prepared generated manifest](../benchmarks/png-bmp-generated-corpus-20261028.json)
binds the proposed learning/profile source hashes before any experiment.

## Proposed learning exposure

- Both unchanged grayscale/RGB SRNet skeletons; model seeds 2026102301 and
  2026102302, four fresh fits. FP32 256×256, 0–255 scale, AMP/TF32 off.
- Generator `generated-even-spatial-scattered-40p0-v1`, data seed 2026102801.
  Per mode: eighty generated train originals and twenty-four generated
  development originals, with disjoint mode/split/index namespaces. Each
  original has its generated forty-percent, byte-rounded plane-0 control.
- Even-valued covers deliberately create an artificial, strong LSB signal.
  A pass demonstrates learning only on this distribution; it does not qualify
  native steganalysis, old JPEG recipes, cover cleanliness or deployment.
- Scalar FP32 AdamW, learning rate 1e-4, betas .9/.999, epsilon 1e-8,
  weight decay zero, foreach/fused false. Eight images/four pairs per step,
  twenty epochs, twenty steps/epoch: 400 updates per fit /1,600 total and
  12,800 training image presentations. No early stopping, sweep or batch fallback.
- Save every training-step loss/debit. Score the complete bound train and
  development sets before and after each fit only, using stored BatchNorm
  state and fixed cover/control ordering. Retain full score arrays for
  independent AUC replay. No development threshold search or epoch selection.
- Proposed all-cells rule: each of the four final fits has train AUC >=.85,
  development AUC >=.70 and final-epoch mean loss <=80% of first-epoch mean.
  Preserve every failure and score; no rerun, tuning or subset selection after
  observing results. These thresholds are proposals, not a frozen executed gate.

## Proposed full-step preparation profile

Use fresh generator seed 2026102802 and fresh model instances, separately from
the learning corpus. Four model/seed cells, each with four generated originals
at batch eight: one warm-up and three measured complete optimizer steps.
This charges **sixteen generated optimizer updates**, not zero. Explicitly
measure generation/decoding, evaluation and numeric checkpoint write/read/restore
as well as the full steps, model/optimizer and allocator/RAM peaks. Profile
decoding includes the scalar payload oracle. Actual PNG/BMP file encoding,
bounded image loading and their I/O costs require an additional generated
transport adapter in the final supervisor; the current in-memory API alone
does not provide them. Profile
weights do not initialize the later fits. A profile failure forbids fitting.
The old T4 forward/backward-only result remains consumed and unchanged.

One independent proposed allowance covers the profile and all four fits:
1,800 seconds total, 8-GiB resident RAM /zero swap, at most 4-GiB Torch allocator
and 512-MiB cumulative numeric outputs, including logs/telemetry/checkpoints.
Actual cost is **unmeasured**. The final supervisor must freeze its whole
source/data/environment closure and demonstrate that the projected complete
workload fits before the learning stage. A failed/OOM/deadline attempt is
unavailable and cannot fall back or retry. Checkpoints are software evidence,
not permission to relaunch. No previous JPEG/WAV time or transfer is reused.

The final acceptance contract must also cover independent consumption records,
all payload checks, disjoint manifests, exact update counts, score arrays,
unchanged initializations/order across any matched comparison, and separately
reported unavailable telemetry. The current software library alone does not
implement or authorize this complete supervised experiment.
